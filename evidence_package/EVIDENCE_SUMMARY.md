# Corrected evidence (v0.2.0)

This directory contains 35,640 supervised and 990 sampled-origin Chronos results, with a separate 60-row full-origin subset. RMSE wins are 39, 119 and 1 respectively; all-three wins are 20, 67 and 1. Counts are descriptive: related rows and duplicate list memberships are not independent observations. No row-independent confidence interval or p-value is reported.

`combined_model_results.csv` preserves all supervised and sampled conditions. The full-origin subset is separate. Source paths are made relative; metric values retain double precision. `split_boundary_exact.csv` records all 1,980 actual supervised conditions. The linear temporal proxy retains the legacy `dlinear` source key and is not official DLinear. The Chronos protocols differ from the supervised protocol.

Full dated forecast CSVs are distributed in `data/forecast_traces/*.zip`; `python prepare_artifacts.py` restores them. The original trained checkpoints/scalers are not part of the public download and are regenerated by full training. The historical v0.1.2 results remain available through the earlier Git tag and Zenodo version; they are not the corrected evidence here.
