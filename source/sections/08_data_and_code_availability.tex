\section{Data and code availability}

Yahoo Finance provides the daily price data used in this study. The original public code and evidence archive is available through \url{https://doi.org/10.5281/zenodo.20412777}, including version 0.1.2 at \url{https://doi.org/10.5281/zenodo.20412970}. That archive contains the earlier evaluation and does not supply the corrected results reported here. The corrected source, manifests, predictions, checkpoints, and verification outputs currently remain in the local batch \texttt{full\_corrected\_20261109}. The revised supplementary material reports the corrected tables and protocol details; a public corrected archive requires a separate release.
