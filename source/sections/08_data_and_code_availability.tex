\section{Data and code availability}

Yahoo Finance provides the daily prices used in this study. Release v0.2.1 contains the corrected code, exact input snapshot, complete result tables, and dated forecast files at \url{https://doi.org/10.5281/zenodo.24168592}. The matching GitHub release is available at \url{https://github.com/Jack-TCN/stock-price-persistence-audit/releases/tag/v0.2.1}. The concept DOI \url{https://doi.org/10.5281/zenodo.20412777} identifies all archived versions. The earlier v0.1.2 archive at \url{https://doi.org/10.5281/zenodo.20412970} preserves the pre-correction evaluation. The public release excludes fitted checkpoints and scaler objects; the original local batch retains them, and full reproduction regenerates them.
