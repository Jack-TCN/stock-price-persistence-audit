\section{Included Artifacts}

The evidence package contains the following generated files:
\begin{itemize}
\item \texttt{combined\_model\_results.csv}: unified supervised and Chronos result rows.
\item \texttt{model\_gate\_summary.csv}: model-level pass rates and RMSE-ratio confidence intervals.
\item \texttt{model\_horizon\_summary.csv}: horizon-level summaries.
\item \texttt{dataset\_model\_summary.csv}: dataset-by-model summaries.
\item \texttt{best\_100\_model\_rows.csv} and \texttt{worst\_100\_model\_rows.csv}: row-level extremes.
\item \texttt{chronos\_full\_origin\_subset\_60\_rows.csv}: the 60-row full-origin Chronos subset verification cited in the main manuscript.
\item \texttt{FULL\_ORIGIN\_SUBSET\_SUMMARY.md}: a compact summary of the full-origin subset verification.
\end{itemize}
