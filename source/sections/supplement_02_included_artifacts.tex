\section{Results and evidence files}

Tables~\ref{tab:sup_market} and~\ref{tab:zero_market} separate supervised and sampled-origin results by asset list. Table~\ref{tab:full_subset} reports the small full-origin subset, which contains nine unique tickers. Tables~\ref{tab:best_rows} and~\ref{tab:worst_rows} retain the price mode, feature set, horizon, and seed for selected supervised rows. All win counts use strict comparisons at full precision, so a displayed ratio rounded to 1.00 does not determine a gate result. The underlying files retain full numeric precision and the complete experiment keys.

The local evidence directories \texttt{corrected\_evidence} and \texttt{full\_origin\_evidence} contain separate combined results and model, horizon, and list summaries. Per-run files retain input and source hashes, arguments, package versions, dated predictions, and verification outputs. The supervised batch also stores fitted checkpoints and feature scalers. The project preserves the old archive, so its original numbers remain traceable rather than silently overwritten. A later public release must identify the corrected batch separately.
