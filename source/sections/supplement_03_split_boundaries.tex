\section{Actual time splits}

The split rule assigns 72\%, 8\%, and 20\% of each condition's usable observations to training, validation, and testing before boundary removal. Training and validation labels must have target dates strictly before the next segment's first forecast origin. Table~\ref{tab:split_ranges} shows the minimum and maximum first-origin dates across assets and price modes for each list, feature set, and horizon. A range denotes variation across conditions, not an interval used as one shared split. The complete file \texttt{split\_boundary\_exact.csv} records dates, retained sample counts, and removed boundary rows for all 1,980 conditions.
