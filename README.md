## Packaging correction

Packaging erratum, v0.2.1: the v0.2.0 manifest recorded Windows working-tree line endings for two unchanged pre-existing files (LICENSE and evidence_package/dataset_coverage.csv), while GitHub archived their existing LF Git blobs. This made the default verifier correctly fail closed. v0.2.1 aligns those two manifest hashes with the archived bytes. All experiment result files, exact input snapshot, forecast archives, training sources and reported scientific values are unchanged. v0.2.0 is retained for provenance. Both the working tree and staged Git blobs are now checked before publication.

## Inspect and verify without training

Use Python 3.13. The original runtime versions are recorded in `provenance/environment_freeze.txt`. For saved-forecast verification only, install `numpy`, `pandas` and `ta`; the fully pinned reproduction environment is in `requirements_submission.txt`.

```bash
python prepare_artifacts.py
python verify_results.py
python verify_results.py --all-runs --data-run data/input_snapshot --forecast-only
```

The first command validates and extracts the exact input snapshot and all 36,690 dated forecast CSVs. The no-argument verifier checks the published package hashes, result keyspaces and derived tables. The last command reconstructs test origins and target dates, matches original prices and persistence, and recalculates all saved forecast errors and gates. `--forecast-only` explicitly excludes fitted checkpoint/scaler validation: those approximately 8.97 GB of objects remain local and are regenerated by training. The original full local verification reports retain their checkpoint hashes. The public manifests redact only local filesystem paths and identify that transformation.

## Re-run training and generation

```bash
python -m pip install -r requirements_submission.txt
python run_all_reproduce.py --data-run data/input_snapshot --out-dir new_run --model-revision a971ba21945c4f1796b17a91fe69214b5f4ad472 --device auto
python verify_results.py --run-dir new_run/supervised --data-run data/input_snapshot
```

This is a long-running full experiment; the saved-evidence commands above do not train. Use a new output directory, not the published `runs/`. Resume refuses changed input/source/configuration/runtime signatures. Training uses window 60, seeds 42/123/777, batch 128, maximum 80 epochs and patience 8. The original pre-correction environment/weights were unavailable, so this release does not claim bitwise reproduction of the historical run.
