# Data Notice

This repository provides derived audit outputs, summary tables, manuscript source, and reproduction scripts.

The underlying daily market-price data are not presented as a standalone commercial data product. They are obtained by ticker symbol and date range from public market-data interfaces during reproduction. Users reproducing the study should comply with the terms of the market-data provider they choose.

The code in this repository is licensed under the MIT License. Manuscript text, figures, tables, and derived evidence artifacts are intended for scholarly review and citation with attribution to the repository and the associated Zenodo DOI once minted.
